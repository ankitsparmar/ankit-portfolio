Side project

An MCP server for SAP BTP administration

I've been building and using a Model Context Protocol server that lets an AI assistant handle routine BTP admin conversationally instead of through endless cockpit clicks. Today it can:

  • Manage entitlements and assign them across multiple subaccounts
  • Run full create, read, update and delete for users and role collections
  • Enable the Cloud Foundry environment and manage subaccount trust configuration
  • Audit users, analyse the global account and report on entitlements

Not there yet: Cloud Foundry spaces and users, directories, service instances, Kyma enablement and role variations from templates. Knowing where the gaps are matters as much as what it automates.
